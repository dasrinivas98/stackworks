# StackWorks website

A responsive, static landing page for StackWorks internship and final-year project programs. It uses plain HTML, CSS, and JavaScript, so it can be hosted with GitHub Pages without a build step.

## Preview locally

Open `index.html` in a browser. Fonts load from Google Fonts; the page otherwise has no runtime dependencies.

## Publish with GitHub Pages

1. Create a GitHub repository and add these files at the repository root.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. For `stackworks.in`, add the custom domain in Pages settings and configure the DNS records GitHub provides. Set up HTTPS once DNS is verified.

If you use a `www` subdomain, add the corresponding DNS record and redirect the apex domain as GitHub Pages documents.

## Before launch

- Inquiries go to `info@stackworks.in`; update the `mailto:` links if the address changes.
- Add real program details, eligibility, pricing, mentor information, and examples of student work before accepting applications.
- Add a privacy notice if you later collect applications through a form or analytics.
